GabOptimization (Fabric 1.21.11)
- Right Shift (змінюється в Керуванні) -> HUD з FPS і кнопкою ON/OFF.
- ON: мод сам знижує графіку при FPS < 45 і повертає при FPS > 110.
- OFF: усі налаштування повертаються як були.

Збірка: скопіюй папку gradle/ та gradlew, gradlew.bat з іншого свого мода (або `gradle wrapper`),
потім: ./gradlew build  ->  build/libs/gaboptimization-1.0.0.jar

GitHub: завантаж проєкт у репозиторій -> вкладка Actions -> build -> Artifacts -> GabOptimization (там .jar).
